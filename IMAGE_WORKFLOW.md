# Image Workflow Guide

This guide explains how to process and add product images to the FzLounge website.

## 📋 Overview

The image workflow consists of three main steps:
1. **Collect** - Gather distributor images
2. **Process** - Optimize for web using automated script
3. **Deploy** - Update JSON and commit to GitHub

---

## 🎯 Image Requirements

### Source Images
- **Format:** JPG, PNG, GIF, or BMP
- **Quality:** Mixed quality screenshots from distributors are acceptable
- **Resolution:** Any resolution (will be resized automatically)

### Output Specifications
- **Format:** WebP (primary) + JPEG (fallback)
- **Card Size:** 600×600px (for product grid)
- **Detail Size:** 1200×1200px (for product detail view - Phase 2)
- **Target File Size:** <100KB per image
- **Quality:** 85%

## 🚀 Step-by-Step Workflow

### Step 1: Collect Images (5 minutes)

1. **Download** product images from your distributor
2. **Rename** using this convention:
   ```
   product-[ID]-[slug].jpg
   
   Examples:
   product-016-pokemon-booster.jpg
   product-017-mtg-single-card.jpg
   product-018-yugioh-deck.jpg
   ```
   
   - **ID:** Next available number (001, 002, 003...)
   - **Slug:** Short descriptive name (lowercase, hyphens)

3. **Place** all images in `assets/products/originals/`

---

### Step 2: Process Images (2 minutes)

Open PowerShell in the repository root and run:

```powershell
.\scripts\optimize-images.ps1
```

**What it does:**
- ✅ Resizes all images to 600×600px
- ✅ Creates WebP versions (modern, smaller)
- ✅ Creates JPEG fallbacks (compatibility)
- ✅ Optimizes file size (<100KB each)
- ✅ Maintains aspect ratio with padding

### Step 3: Update products.json (5 minutes)

Open `data/products.json` and add a new product entry:

```json
{
  "id": 16,
  "name": "Pokémon Scarlet & Violet Booster",
  "game": "pokemon",
  "condition": "sealed",
  "category": "booster",
  "description": "Sealed booster pack from Scarlet & Violet set. Chase rare cards!",
  "image": "assets/products/optimized/product-016-pokemon-booster.webp",
  "imageFallback": "assets/products/optimized/product-016-pokemon-booster.jpg",
  "imageAlt": "Pokémon Scarlet & Violet booster pack",
  "featured": false,
  "dateAdded": "2025-01-29",
  "status": "presale",
  "releaseDate": "2025-02-15"
}
```

**Field Explanations:**

| Field | Required | Description | Example |
|-------|----------|-------------|---------|
| `id` | ✅ Yes | Unique number (increment from last) | `16` |
| `name` | ✅ Yes | Product name | `"Pokémon Scarlet & Violet Booster"` |
| `game` | ✅ Yes | Game code (see list below) | `"pokemon"` |
| `condition` | ✅ Yes | Product condition | `"sealed"` |
| `category` | ✅ Yes | Product category | `"booster"` |
| `description` | ✅ Yes | Short description (1-2 sentences) | `"Sealed booster..."` |
| `image` | ✅ Yes | Path to WebP image | `"assets/products/..."` |
| `imageFallback` | ✅ Yes | Path to JPEG image | `"assets/products/..."` |
| `imageAlt` | ✅ Yes | Accessibility text | `"Pokémon booster pack"` |
| `featured` | ✅ Yes | Show on homepage? | `true` or `false` |
| `dateAdded` | ✅ Yes | Date added (YYYY-MM-DD) | `"2025-01-29"` |
| `status` | ✅ Yes | Availability status | `"presale"`, `"available"`, `"limited"`, `"sold"` |
| `releaseDate` | ⚠️ If presale | Release date (YYYY-MM-DD) | `"2025-02-15"` |

**Game Codes:**
- `mtg` - Magic: The Gathering
- `pokemon` - Pokémon
- `yugioh` - Yu-Gi-Oh!
- `lorcana` - Lorcana
- `riftbound` - Riftbound
- `grandarchive` - Grand Archive
- `digimon` - Digimon TCG
- `gundam` - Gundam TCG
- `onepiece` - One Piece TCG
- `other` - Other/Accessories

**Status Options:**
- `presale` - Not yet released (shows red badge 🎁)
- `available` - In stock (shows green badge 📦)
- `limited` - Limited availability (shows orange badge ⚡)
- `sold` - Sold out (shows gray badge 🔒)

## 🔧 Advanced Options

### Process Only Card Size (600×600)
```powershell
.\scripts\optimize-images.ps1 -Size card
```

### Process Only Detail Size (1200×1200)
```powershell
.\scripts\optimize-images.ps1 -Size detail
```

### Adjust Quality (1-100, default 85)
```powershell
.\scripts\optimize-images.ps1 -Quality 90
```

### Skip WebP Generation (JPEG only)
```powershell
.\scripts\optimize-images.ps1 -SkipWebP
```

## 🐛 Troubleshooting

### ImageMagick Not Found

**Error:**
```
Checking ImageMagick installation... NOT FOUND
```

**Solution:**
1. Install ImageMagick from link above
2. Add to PATH during installation
3. Restart PowerShell
4. Try again

---

### Script Execution Policy Error

**Error:**
```
.\scripts\optimize-images.ps1 : File cannot be loaded because running scripts is disabled
```

**Solution:**
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Then try running the script again.

---

### Images Not Appearing on Website

**Check:**
1. ✅ Image paths in `products.json` are correct
2. ✅ Images exist in `assets/products/optimized/`
3. ✅ Changes committed and pushed to Git
4. ✅ GitHub Pages has rebuilt (wait 2 minutes)
5. ✅ Hard refresh browser (Ctrl+Shift+R)

---

### Image Too Large (>100KB)

**Solution:**
Lower the quality setting:
```powershell
.\scripts\optimize-images.ps1 -Quality 80
```

Or manually compress using https://squoosh.app/

## 🎓 Tips & Best Practices

### Image Naming
✅ **Good:**
- `product-016-pokemon-sv-booster.jpg`
- `product-017-mtg-dominaria-box.jpg`
- `product-018-yugioh-starter-deck.jpg`

❌ **Avoid:**
- `IMG_20250129_153045.jpg`
- `photo-1.jpg`
- `NEW PRODUCT!!!.jpg`

### Product Descriptions
- Keep it concise (1-2 sentences)
- Mention key features
- Include condition details if relevant
- Highlight what makes it special

### Status Updates
Update the `status` field weekly:
- When presale items release → change to `available`
- When stock runs low → change to `limited`
- When sold out → change to `sold`

### Featured Products
- Keep 3-6 products featured at a time
- Feature new arrivals or popular items
- Update monthly for variety
